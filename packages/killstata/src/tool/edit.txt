# 精确编辑文件
对已有文本文件执行可审查的字符串替换。

- 修改前必须先用 read 读取目标文件；filePath 使用真实路径，不猜测目标。
- oldString 必须来自刚读到的原文，保留真实缩进，不包含 read 展示的行号前缀；newString 必须与 oldString 不同。
- oldString 找不到时先重新读取并检查内容是否变化；命中多处时增加上下文使目标唯一。只有明确要修改全部命中时才使用 replaceAll。
- 优先精确修改已有文件；创建新文件使用 write。不得借编辑顺手重构相邻内容，也不要添加用户未要求的文档或装饰。
- 编辑会改变文件。覆盖关键配置、工作目录外文件或影响共享系统前必须获得本次范围的确认；失败后不要放宽匹配条件盲改。
