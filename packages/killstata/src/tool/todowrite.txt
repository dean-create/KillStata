# 更新内部任务清单
仅为用户请求的复杂多步骤分析或多个并列任务维护执行状态。

- todos 中每项包含 content，并可提供 status、priority 和 id；status 只能是 pending、in_progress、completed 或 cancelled，priority 只能是 high、medium 或 low。
- 同一时间最多一个任务处于 in_progress。开始时及时标记，完成后立即改为 completed，失去意义的任务改为 cancelled。
- 单个分析请求、简单问题和例行操作不使用任务清单。清单不能替代实际工具执行、证据核验或面向用户的结论。
- 不虚构进度，不把失败任务标为完成，也不因计划变化删除仍需追踪的阻塞项。
