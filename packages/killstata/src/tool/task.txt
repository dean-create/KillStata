启动一个边界明确的内部子任务，用于把可独立验证的探索或核验工作交给合适的子 Agent。

## 当前可用子 Agent
{agents}

- 仅用于可独立完成、不会与当前任务重复且确实能降低主任务复杂度的工作；简单读取或单步操作由主 Agent 直接完成。
- 描述必须写清目标、上下文边界、输入数据/文件、允许的操作、禁止事项、成功标准和预期交付。
- subagent_type 必须从上方真实列表选择；description 用 3 至 5 个中文词概括任务，prompt 提供子 Agent 可独立执行所需的完整上下文。需要继续既有子任务时传 session_id，不要新建重复会话。
- 默认优先只读子任务。需要分析或写入时，必须与子 Agent 能力和授权范围一致；不得借子任务绕过权限、工具阶段或用户确认。
- 多个子任务只有在彼此无依赖、不会写同一数据 stage 或产物时才能并行；否则按依赖顺序执行。
- 不得重复派发已经进行中或已经有可信结果的任务。子 Agent 失败时先读取其错误和已完成内容，不盲目重新创建相同任务。
- 子任务返回时必须区分事实、推断和未验证项，并给出发现、产物及下一步建议；主 Agent 仍负责核验并向用户形成最终结论。
- 用户看不到子 Agent 的原始返回。主 Agent 必须用中文提炼可信发现；不要把子 Agent 输出未经核验地当成最终事实。
