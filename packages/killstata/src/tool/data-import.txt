导入表格、画像和数据质量检查，管理可追溯数据集；会话隔离。

## 何时使用
- healthcheck：确认托管 Python 与依赖可用；环境不确定或首次导入失败时先检查。
- import：导入 xlsx/xls/csv/dta/sav，生成规范化数据和就绪报告（类型、缺失、面板键、共线、适配方法）；估计前必需。
- profile：读取 stage 的字段、类型、缺失、唯一性和样本概况，并刷新其就绪报告。
- frequency：对 variables 和最多两列 groupBy 返回有界频数/比例/交叉频数；只给高频值，不生成行级 CSV，适合诊断 did×post。
- correlation：对指定 variables 返回 Pearson 相关及显著性摘要；仅报告相关性，不代替回归。
- export：仅在用户需要交付文件时，将规范化 stage 导出为 csv/xlsx/dta/parquet。
- rollback：从 manifest 血缘恢复到目标 stage，生成新的规范化 Parquet，不覆盖历史阶段。

## 数据质量检查 / 数据质量
- import validate，生成 blocking_errors/warning；不能跳过。
- 质量体检只交付 import/profile/validate/frequency 事实；zscore_detect/iqr_detect 和新 stage 仅按用户要求。
- 质量摘要足够时直接回答；除非用户明确要求补充诊断，不再调用 profile/validate/frequency 或读取内部产物。

## 参数与返回
- inputPath 必须来自用户提供的路径或已发现的真实文件，不得猜测。
- Excel 工作表名称必须来自已发现的 sheetPolicy.sheetName；未知时省略该字段，由工具返回候选工作表后再决定。
- 后续动作使用工具返回的 datasetId 与 stageId，不得自造或复用其他会话的内部 ID。
- variables/groupBy/entityVar/timeVar 必须来自 profile 真实列；仅对齐唯一别名并说明。
- preserveLabels 仅用于 import/export 的 DTA 标签处理；其他 action 省略该参数。
- runId/branch 仅用于归组；outputPath/format 仅用于导出。
- 依据 metadata.result、产物引用和状态判断成功；结构化结果与预期产物齐全才声称导入完成。

## 边界与失败
- 此工具没有 filter 或 preprocess 动作；缩尾、填补、标准化、虚拟变量、列组合和筛选必须使用 data_preprocess。
- validate 的 blocking_errors 会阻断下游估计；warning 可以继续，但必须向用户说明影响。
- import 自动 validate block 会保留数据并提示“暂不能估计”；当前 stage 重新 validate 后再继续。
- 工具失败时先检查结构化错误与失败阶段，只修复失败部分；不得原样盲目重试。用户取消时立即停止，不安排自动重跑。
- 列名不存在时先读 profile/data-readiness；有唯一别名就只用对齐名重试失败动作；有多个候选或会改变研究设计时停下询问。
- 不覆盖/删除源文件，不上传内容，不向普通用户暴露内部 manifest 路径。
- 返回并复用 dataset/stage、就绪报告、结果和 numeric snapshot；不生成行级副本。
