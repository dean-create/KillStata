# 终端命令
在持久 Shell 会话中执行没有专用工具可替代的命令。默认工作目录是 ${directory}；需要其他目录时使用 workdir，不要在 command 中拼接 cd。

## 适用场景
- 检查托管 Python、系统依赖或运行环境；运行用户明确要求的受控命令。
- KillStata 是计量分析工作台，不默认把用户目录当成代码仓库。除非用户明确在 Git 项目中请求，否则不要提交、推送、建分支或创建 PR。

## 专用工具优先
- 读文件用 read，精确修改用 edit，创建/覆盖用 write，找路径用 glob/list，搜文本用 grep。
- 数据导入、画像和 数据质量检查 用 data_import；清洗用 data_preprocess；估计用专用计量工具。不得用 Shell 绕过这些工具的 schema、权限、血缘或 数据质量检查 门禁。
- 不要用 find、grep/rg、cat、head、tail、sed、awk、echo 重定向代替已有专用工具；输出过长会自动截断，无需手工截流。

## 参数与执行
- command 必填；description 用 5 至 10 个中文词说明目的，便于用户审查。
- timeout 为可选毫秒数，默认 120000，最大 900000；不要用超长超时掩盖卡死。
- 含空格的路径必须正确引用。创建文件或目录前先用 list 核对父目录与目标位置。
- 输出超过 ${maxLines} 行或 ${maxBytes} 字节时会截断并保存完整结果；再用 read 的 offset/limit 或 grep 查看相关部分。
- 互不依赖、只读且安全的命令可并行调用；存在依赖的命令按顺序执行。不要用分号忽略前序失败。

## 安全与失败
执行前按可逆性和影响范围判断风险。删除、覆盖、修改工作目录外内容、联网上传、安装依赖或影响共享系统必须先获得针对本次范围的授权。失败时先读退出码和错误输出，核对命令、工作目录、引用和依赖，再做最小修复；不得原样盲目重试。
